# Phoenix — العنقاء (Threat Intelligence & Forensic Suite v2.0)

**Phoenix — العنقاء** منصة استخبارات تهديدات وتحقيق جنائي رقمي دفاعي (Defensive Threat Intelligence & Forensic Suite) مفتوحة المصدر. صُممت لفحص وتفكيك الروابط المشبوهة، كشف صفحات التصيد وانتحال العلامات التجارية، تمييز أرقام الـ VoIP الوهمية عن الشرائح الحقيقية، والتحليل الجنائي للصور والمرفقات (EXIF & ELA).

الإصدار `2026.2.0` محلي بالكامل (Local-First)، بدون اشتراكات أو سيرفرات وسيطة، ومبني بمبدأ الخصوصية الصارمة.

| الوظيفة الجنائية | الحالة | الملاحظات التقنية |
| --- | --- | --- |
| **فك تمويه الروابط وسلاسل التحويل (Deep URL Uncloaker)** | متاحة دائماً | تتبع سلاسل الـ Redirects المتعددة، فحص الـ Headers، واستخراج الوجهة الحقيقية بأمان تام. |
| **كشف انتحال البراندات بالأيقونات (Favicon Spoof Detection)** | متاحة دائماً | حساب البصمة التشفيرية للأيقونة ومطابقتها مع خوادم Meta, Google, Microsoft, PayPal لكشف التصيد. |
| **استخبارات عمر الدومين (ICANN RDAP)** | متاحة دائماً | استعلام مباشر لبروتوكول RDAP لتحديد عمر النطاق ومزود التسجيل وحساب درجة الخطورة للدومينات الحديثة (< 30 يوماً). |
| **كشف أرقام الـ VoIP السحابية (Disposable VoIP Gateways)** | متاحة دائماً | كشف مزودي الاتصال السحابي المؤقت (Twilio, TextNow, Bandwidth) وتمييزها عن شرائح الـ SIM الحقيقية. |
| **فحص الصور الجنائي (EXIF & GPS Telemetry)** | متاحة دائماً | استخراج بيانات الكاميرا، برامج التعديل (Photoshop/Canva)، والتوقيت الحقيقي وإحداثيات الموقع الجغرافي. |
| **كشف التلاعب بالصور (Error Level Analysis - ELA)** | متاحة دائماً | خوارزمية فحص تباين ضغط الـ JPEG لكشف التزوير في لقطات الشاشة والإيصالات المحررة. |
| **توليد ملف القضية الجنائية (Evidence Dossier Export)** | متاحة دائماً | توليد تقرير جنائي رسمي (Markdown / JSON) موثق بالتوقيعات التشفيرية SHA-256 لتقديمه لفرق الدفاع والجرائم الإلكترونية. |
| **بيانات خطط الترقيم الجغرافية (Numbering Plan Metadata)** | متاحة دائماً | فحص التنسيق الدولي والمشغل والمنطقة الزمنية عبر مكتبة `phonenumbers`. |
| **فحص المنافذ والشبكة** | مقيد بالتفويض | فحص المنافذ المصرح بها عبر `nmap -F` بمهلة 60 ثانية. |

## التثبيت

يتطلب المشروع **Python 3.10+**، وبيئة Tk المثبتة ضمن توزيعة بايثون المعتادة. يفضَّل استخدام بيئة افتراضية مستقلة.

```bash
git clone https://github.com/Khalil-M-Khalil/Phoenix.git
cd Phoenix
python -m venv .venv
```

فعّل البيئة الافتراضية ثم ثبّت النسخة الأساسية:

| النظام | التفعيل | تثبيت النسخة الأساسية |
| --- | --- | --- |
| Linux/macOS | `source .venv/bin/activate` | `python -m pip install .` |
| Windows PowerShell | `.venv\Scripts\Activate.ps1` | `python -m pip install .` |

لتفعيل ميزات الإثراء الاختيارية، ثبّت مجموعة `osint`:

```bash
python -m pip install ".[osint]"
```

يمكن أيضاً استخدام المسار المتوافق مع المشروع القديم:

```bash
python -m pip install -r requirements.txt
```

## التشغيل

بعد التثبيت، شغّل التطبيق بإحدى الطريقتين:

```bash
phoenix
# أو
python phoenix.py
```

لا توجد أي خطوة شراء أو تسجيل أو تفعيل أو حدّ للاستخدام.

## الإعدادات الاختيارية

لا تُحفظ مفاتيح الخدمات في المستودع. انسخ أسماء المتغيرات من [`.env.example`](.env.example) واضبطها في بيئة التشغيل لديك عند الحاجة.

```bash
export OPEN_CAGE_API_KEY="your-key"  # خرائط المناطق الاختيارية
export HIBP_API_KEY="your-key"       # فحص بريد تملك الوصول إليه فقط
export GEOAPIFY_API_KEY="your-key"   # إثراء IP اختياري
```

| المتغير | الميزة | مطلوب؟ |
| --- | --- | --- |
| `OPEN_CAGE_API_KEY` | خريطة تقريبية لمنطقة خطة الترقيم | لا |
| `HIBP_API_KEY` | فحص تسريبات البريد عبر المزود | لا |
| `GEOAPIFY_API_KEY` | بيانات وصفية تقريبية لعناوين IP العامة | لا |

```bash
python -m pip install ".[dev]"

```

## الاستخدام المسؤول

تتحقق الواجهة من إقرار المستخدم بالتفويض قبل تنفيذ ميزات الإثراء أو فحص الشبكة. يجب إدخال بيانات أو نطاقات أو حسابات أو عناوين IP **تملكها أو تديرها أو لديك إذن صريح وواضح لتقييمها**. يتحمل المستخدم مسؤولية الالتزام بالقوانين المحلية وشروط مزودي الخدمات.
